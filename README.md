# Student Calculator

A beginner-friendly web project that helps students calculate academic marks and perform basic arithmetic.

## Features

- Add or remove subjects.
- Calculate total scored marks and total maximum marks.
- Calculate percentage and average marks.
- Display a grade based on the percentage.
- Basic calculator for addition, subtraction, multiplication, division, and percentages.
- Responsive layout for desktop and mobile screens.
- Input validation for marks.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Enter subject marks and click **Calculate results**.
4. Use the basic calculator buttons for arithmetic.

No installation or server is required.

## Grade Scale

| Percentage | Grade |
|---|---|
| 90% and above | A |
| 80%–89.99% | B |
| 70%–79.99% | C |
| 60%–69.99% | D |
| Below 60% | F |

This grade scale is an example for the project. Schools and colleges may use different grading rules.
